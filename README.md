# AI Learning Notes

A collection of notes, examples, and starter code for learning Artificial Intelligence and Machine Learning concepts.

## Project Structure

```
ai-learning-notes/
├── README.md
├── requirements.txt
├── basics/
│   ├── linear_regression.py      # Simple linear regression from scratch
│   ├── logistic_regression.py    # Logistic regression for classification
│   └── neural_network.py         # Basic neural network with numpy
├── data_preprocessing/
│   ├── preprocessing.py          # Common data preprocessing techniques
│   └── feature_engineering.py   # Feature engineering examples
└── examples/
    ├── iris_classification.py    # Classic Iris dataset classification
    └── housing_prices.py         # Housing price prediction example
```

## Getting Started

### Prerequisites

- Python 3.8+
- pip

### Installation

```bash
pip install -r requirements.txt
```

### Running Examples

```bash
# Run a basic linear regression example
python basics/linear_regression.py

# Run the Iris classification example
python examples/iris_classification.py
```

## Topics Covered

- **Supervised Learning**: Linear Regression, Logistic Regression, Neural Networks
- **Data Preprocessing**: Normalization, Encoding, Feature Engineering
- **Model Evaluation**: Accuracy, Precision, Recall, F1-Score
